# MECHANICA · 机械蝴蝶

全程序化生成的 Three.js 交互式机械蝴蝶:发光的机械羽翼、精密咬合的发条轮系、流畅灵动的动态表现。无任何外部模型/贴图 —— 几何体、轮系、翼面蒙版、音效全部由代码实时构建。

## 运行

双击 `start.bat`(Windows),或手动:

```bash
cd 本目录
python -m http.server 8123
# 浏览器打开 http://localhost:8123/index.html
```

> Three.js r160 已下载到 `lib/` 本地目录,离线可用;直接双击 index.html(file://)会被浏览器 CORS 拦截,请务必经 HTTP 服务打开。

## 交互

| 操作 | 效果 |
|---|---|
| 按住「⟳ 上弦」/ 空格 | 旋紧主发条,能量上升;能量耗尽会迫降,上弦至 30% 自动起飞 |
| 拖拽 / 滚轮 | 环绕旋转 / 缩放视角 |
| 点击任意零件 | 弹出零件档案(名称、规格、机械原理),并触发一次振翅脉冲 |
| 悬停零件 | 显示名称提示 |
| 配色圆点 | 五套冷光主题(霜蓝 / 流晶紫 / 熔金橙 / 翡光绿 / 绯红) |
| 「展开」滑杆 | 爆炸视图:穹顶掀起、四翼分离、腹节抽出、曲轴外露 |
| 环绕 / 音效 | 自动环绕开关;程序化合成的擒纵滴答与上弦棘轮声 |

## 机械细节(全部真实联动)

- **轮系咬合**:主发条桶 → 二轮 → 同轴小钢齿 → 三轮 → 四轮,齿数与中心距按模数精确计算,相位由啮合方程 `θ₂ = −(N₁/N₂)θ₁ + φ₁₂(1+N₁/N₂) + π/N₂` 驱动,齿与齿槽严格交错。
- **擒纵机构**:锯齿擒纵轮按节拍步进,擒纵叉往复锁放,摆轮游丝以恒频振荡 —— 振翅频率即由这套"心跳"校准。
- **曲轴连杆**:透过胸廓两侧玻璃窗,可见曲柄-连杆随振翅相位推动翼根铰链。
- **发光翼膜**:自定义 Shader —— 数千枚六边形镂空晶格(`discard` 真实镂空)、Canvas 程序化翼脉蒙版、行波辉光、菲涅尔轮廓光,振翅时翼面还有柔性波纹位移。
- **发条经济**:能量同时驱动振翅频率、轮系转速、辉光强度与飞行高度;红灯迫降 → 着陆收翅撑足 → 上弦复飞的完整循环。
