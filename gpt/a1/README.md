# AETHER · 机械之翼

从零构建的 Three.js 交互机械蝴蝶。模型由程序生成，无外部模型或图片依赖。

## 运行

```sh
npm install
npm run build
npm run dev
```

打开 http://127.0.0.1:5173 。`dist` 已包含构建结果，可由任何静态 HTTP 服务器提供。

## 交互

- 鼠标或触控拖动旋转；滚轮或双指缩放。
- 调整振翅速度、辉光和结构展开比例。
- 翡翠青、琥珀金、星云紫三种翼光。
- 暂停、自动环绕、能量粒子、机械共鸣音效。
- 正面、侧面、核心特写三个视角。
- 点击模型触发能量脉冲。
- 聚焦画布后可用方向键旋转，`+`/`-` 缩放，空格切换动画。
- 系统偏好减少动态效果时，初始暂停动画。

## 实现

- `src/main.js`：三维模型、渐开线齿轮、材质、辉光、动画和交互。
- `dist/index.html` / `dist/style.css`：中文控制台与响应式布局。
- `dist/app.js`：包含 Three.js 的构建产物，运行时无需外部 JavaScript CDN。
- `server.mjs`：本地静态服务器。

18 枚齿轮使用统一模数、反向角速度和相应齿数比例；翼内相邻齿轮按节圆相切布置。齿轮、翼框、铆钉、光导纤维、游丝、分节腹部与触须均为真实三维几何。静态构件按材质合并以减少绘制调用。该作品是机械艺术仿真，不用于工程制造校核。

字体在线可用时使用 Noto Sans SC / Space Grotesk，否则回退至本机字体。WebGL2 是三维渲染所必需的。浏览器支持 `document.modelContext` 时，提供状态读取和参数调整两个结构化工具。
