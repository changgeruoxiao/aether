# ÆTHER · 机械蝴蝶

纯 Three.js 程序化建模的机械蝴蝶——无任何外部模型/贴图，全部几何体、传动与着色器由代码生成。

## 运行

```bash
# 任一静态服务器均可（需联网加载 three.js CDN）
python -m http.server 8137
# 打开 http://127.0.0.1:8137/mechanical-butterfly.html
```

## 机械系统（真实传动，非预设动画）

- **轮系**：主发条轮 60T（含阿基米德涡线发条）→ 两侧中心小齿轮 18T → 同轴 48T 大轮 → 长轴 → 翼根曲柄盘。齿形按模数 0.028 生成，`alignMesh()` 相位对齐保证齿齿互插。
- **连杆扇翅**：曲柄销经连杆推动翼根摇臂，翅膀角度每帧由平面二连杆逆解（`solveTwoLink`）实时解出；前/后翅由同盘双销（相位差 75°）驱动，扇翅天然错拍。
- **擒纵机构**：领口处摆轮（含游丝）3Hz 往复 + 擒纵轮 6 步/秒步进 + 红宝石轴眼擒纵叉。
- 全轮系由单一相位源（发条轮角）驱动，调速时相位永不漂移。

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 | 环绕视角 / 缩放 |
| 移动鼠标 | 头部追踪光标；开启「跟随鼠标」后全程引导飞行 |
| 点击画面 | 能量脉冲：冲击波环 + 火花 + 筋斗机动 |
| 面板 | 扇翅速度 / 泛光 / 翼膜色相 / 透视机壳 / 结构分解 / 巡游模式 |

## 视觉

- 翼膜自定义着色器：根→尖能量流带 + 细胞噪声 + 扇翅角速度联动脉冲，加法混合
- UnrealBloom 泛光、ACES 色调映射、RoomEnvironment 金属反射
- 翼尖火花池、环境浮尘、星云穹顶；腹部能量环流动、触角/分节腹部摆动
